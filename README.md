# 🛡️ Безопасный шаг (SafeStep)

Telegram бот для обучения безопасности в интернете. Помогает пользователям распознавать уловки мошенников и защищать себя в цифровом мире.

## 🎯 Возможности

- **📓 Видео-лекции** — краткие, понятные уроки по безопасности
- **🎯 Интерактивные тесты** — практикуйтесь после каждой лекции
- **📊 Прогресс пользователя** — отслеживание пройденных лекций
- **⚙️ Админ-панель** — добавление и редактирование вопросов, загрузка видео

## 🚀 Установка

### Требования
- Python 3.8+
- pip

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd tgbot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` с конфигурацией:
```
TELEGRAM_TOKEN=your_bot_token_here
ADMIN_IDS=123456789,987654321
```

4. Запустите бота:
```bash
python bot.py
```

## 📖 Использование

### Для пользователей

- **/start** — начать обучение, выбрать лекцию
- **/help** — справка
- **/quiz** — случайный вопрос из всех тестов

### Для администраторов

- **/add_question** — добавить новый вопрос
- **/edit_question** — редактировать существующий вопрос
- **/list_questions** — показать все вопросы
- **/upload_lecture** — загрузить видео-лекцию
- **/import_questions** — импортировать тесты из `questions.txt`

## 📋 Формат вопросов

### JSON формат (questions.json)

```json
[
  {
    "id": 1,
    "text": "Как распознать фишинговое письмо?",
    "options": [
      {"label": "А", "text": "Проверить отправителя"},
      {"label": "Б", "text": "Нажать на ссылку"},
      {"label": "В", "text": "Передать пароль"},
      {"label": "Г", "text": "Ничего не делать"}

    "answer": "А",

---
```

## 🔑 Переменные окружения

| Переменная | Описание | Обязательна |
|-----------|---------|-----------|
| `TELEGRAM_TOKEN` | Токен Telegram бота | ✅ Да |
| `ADMIN_IDS` | ID администраторов (через запятую) | ❌ Нет |

Получить токен бота можно у [@BotFather](https://t.me/botfather) в Telegram.

## 🏗️ Архитектура

Бот использует:
- **python-telegram-bot** — асинхронная работа с Telegram API
- **ConversationHandler** — управление состояниями беседы
- **JSON** — хранение данных о вопросах и лекциях

### Основной поток

1. Пользователь нажимает на лекцию
2. Открывается видео (если загружено)
3. Запускаются 15 вопросов из этой лекции
4. При 100% правильных ответов — следующая лекция открывается
5. Иначе — нужно повторить
